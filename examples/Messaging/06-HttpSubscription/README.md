# Example 06: Declarative HTTP Push Subscriptions (`Dapr.Messaging`)

This example demonstrates **HTTP push pub/sub subscriptions** (`DeliveryMode.Http`) in `Dapr.Messaging`.

## Overview

In `DeliveryMode.Http`, the Dapr sidecar queries the application for subscriptions via `GET /dapr/subscribe` and pushes incoming CloudEvents to your configured HTTP endpoint route via `POST`.

### Key Features of HTTP Subscriptions

- **Native AOT Compatible**: Unlike legacy ASP.NET Core controller attributes that relied on runtime reflection and MVC filters, `Dapr.Messaging` generates static dispatchers and route mappings at compile time.
- **Custom Application Routes**: Set `Route = "api/events/invoices"` on `[DaprTopic]` to match your preferred URL schema.
- **Reverse Proxy / Ingress Compatibility**: Works seamlessly behind standard HTTP load balancers and ingress controllers.

## Writing an HTTP Push Topic Handler

```csharp
[DaprTopic("pubsub", "invoices", Delivery = DeliveryMode.Http, Route = "api/events/invoices")]
public class InvoiceProcessingHandler : ITopicHandler<InvoiceGenerated>
{
    private readonly ILogger<InvoiceProcessingHandler> logger;

    public InvoiceProcessingHandler(ILogger<InvoiceProcessingHandler> logger)
    {
        this.logger = logger;
    }

    public Task<TopicResponseAction> HandleAsync(InvoiceGenerated invoice, TopicContext context, CancellationToken ct)
    {
        if (invoice.TotalAmount <= 0)
        {
            return Task.FromResult(TopicResponseAction.Drop);
        }

        return Task.FromResult(TopicResponseAction.Success);
    }
}
```

## Configuring `Program.cs`

```csharp
var builder = WebApplication.CreateBuilder(args);

// Discovers HTTP [DaprTopic] handlers at compile time
builder.Services.AddDaprMessaging();

var app = builder.Build();

// Exposes GET /dapr/subscribe and maps POST routes
app.MapDaprMessaging();

app.Run();
```

## Running the Example

Run with `--app-port` pointing to the application's HTTP port:

```bash
dapr run --app-id http-subscriber-example \
         --app-port 5000 \
         --dapr-grpc-port 50001 \
         -- dotnet run --project examples/Messaging/06-HttpSubscription/HttpSubscription.Example06.csproj
```

Inspect the subscription manifest generated by Dapr.Messaging:

```bash
curl http://localhost:5000/dapr/subscribe
```
